在英语里，它最常见也最受人喜爱的形式，通常被叫作西米布丁 或西米啫喱。然而，这两个说法太有误导性了，因为它们仿佛在暗示 （a）所说的这种食物有布丁或啫喱的黏稠度，（b）所谓的这种食物就 像布丁或啫喱一样诱人。 这两种暗示都错得离谱。这种被称为西米“布丁”或“啫喱”的 食物的质地实际上更像是烂泥或黏痰。它的黏性如此之好，以至于一 口还在你嘴巴里的时候，其余部分已经悬到喉咙里了，就像一口又长 又稠的痰挂在那儿似的。这甚至不是西方很多人视作食物应有的黏稠 度。当有什么稀溜溜的东西像鼻涕一样顺着嗓子眼儿滑下去时，我们 的反应是想吐出来，而不是吞下去。 西米啫喱也不诱人一—当然，除非你正好是一个塞皮克河沿岸村 78 雨林里的消亡 [PAGE 88 IMAGE 1 CONTENT (OCR)]: 子的人，生来就是吃这个长大的（婴儿刚出生几天后，迦普恩的村民 就开始喂他们吃西米啫喱）。它没有什么味道，这是它唯一不讨人嫌 的地方一除非做的时候在不干净的水里洗过，这样就能尝出家具抛 光料的味道。西米啫喱的颜色不一，从淡粉到深红乃至黑色都有，取 决于过滤时的水质。
